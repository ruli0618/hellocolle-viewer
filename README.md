# ハロコレ ビューア

E:\ハロコレ にある9グループの JPG・PNG・WebP・MP4 を、ブラウザで探してプレビューするサイトです。イベント一覧、ファイル名検索、写真・動画フィルター、お気に入り、動画のシーク、キーボード操作に対応しています。グループは[ハロー！プロジェクト公式サイト](https://helloproject.com/)の掲載順を基本に並べています。

オンライン版: <https://ruli0618.github.io/hellocolle-viewer/>

オンライン版のメディアはグループ別の公開 GitHub リポジトリに保管します。ファイルは元画質のままです。GitHub Pages の容量制限に合わせ、サイト本体と顔が見えやすいサムネイルをこのリポジトリの `docs/` に置いています。★5動画はサイト再生時に音量を約8%に下げます。お気に入りは閲覧端末のブラウザに保存されます。

## 起動

Windows で Python 3.10 以降と FFmpeg を PATH に用意してください。PowerShell でこのフォルダを開き、次を実行します。

```powershell
python -m pip install -r requirements.txt
python server.py
```

ブラウザで <http://127.0.0.1:8765> を開いてください。初回起動時にフォルダを走査します。ファイルを追加した後は画面右上の ↻ で再読み込みできます。サムネイルは初回表示時に生成され、`work/thumbnails` にキャッシュされます。元ファイルは変更しません。

## スマートフォンから見る

PC とスマートフォンを同じ Wi-Fi に接続し、次のように起動します。

```powershell
python server.py --host 0.0.0.0
```

PowerShell で `ipconfig` を実行し、PC の IPv4 アドレスを確認して、スマートフォンで `http://PCのIPv4アドレス:8765` を開きます。Windows ファイアウォールの許可が必要な場合があります。共有 Wi-Fi やインターネットへポートを公開しないでください。このサーバーにはログイン機能がありません。

## データの場所

既定のメディアフォルダは `E:\ハロコレ` です。移動した場合は `server.py` 冒頭の `ROOT` を変更してください。対象グループは `GROUPS` で変更できます。メディア本体と生成サムネイルは GitHub にアップロードしません。

お気に入りは閲覧に使ったブラウザのローカルストレージに保存されます。ブラウザや端末を変えると共有されません。

## サムネイル生成

顔の位置を検出し、その周辺と上半身が入りやすいよう切り取っています。顔を検出できない画像では上寄りの中央を使います。顔検出には OpenCV Zoo の [YuNet](https://github.com/opencv/opencv_zoo/tree/main/models/face_detection_yunet) モデルを使用しています。モデルのライセンスは `models/LICENSE` を参照してください。
